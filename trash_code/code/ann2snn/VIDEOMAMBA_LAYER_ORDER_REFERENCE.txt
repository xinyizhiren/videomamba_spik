3. build cls_token

ANN-to-SNN insertion points used by the converter
=================================================

A. patch_embed output -> patch_spike
B. layers.0 output -> block_spikes["0"]
C. layers.1 output -> block_spikes["1"]

These are the default conversion points.
For exact leaf-module execution order and tensor shapes, run:

python ann2snn/dump_videomamba_layer_order.py \
  --checkpoint ./outputs/videomamba_small_cv_train12_test3_ann_clean_full/best.pth \
  --output ./outputs/ann2snn_videomamba/videomamba_layer_order.txt
